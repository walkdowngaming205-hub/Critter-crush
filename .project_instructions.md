# Critter Crush — Project Notes
- Frontend-only Expo match-3 game (expo-router, react-native-paper, Reanimated 4, AsyncStorage key `critter_crush_state_v1`). Follows ux_design.md.
- Theme: bg #FFF8F0, coral #FF6B6B, violet #A855F7; fonts Fredoka One (display) / Nunito (body), with web fallbacks. Gradients are `as const` tuples in src/theme.
- Structure: src/engine (pure logic: board.ts, rng.ts), src/hooks/useGameEngine.ts (async cascade, swaps, hints, power-ups), src/state/GameProvider.tsx (global progress, lives, streak, inventory, daily, settings), src/components/{game,ui}, app/ screens (index, level-select, gameplay, daily-challenge, lucky-spin, high-scores, settings).
- Levels: 24. Types go 5→8, moves 30→16. Target = perMove{5:300,6:200,7:140,8:100} × moves × ratio(0.30→0.85), rounded to 50. Stars at target ×1 / ×1.25 / ×1.5.
- Sim harness: /home/ubuntu/critter_crush/sim/sim.ts (compile with tsc to /tmp/simout) validates the engine and pass rates.
- Lives: max 5, +1 every 30 min. A loss, or quitting after moving, costs 1. Daily challenge costs no lives. Streak of 3 days → golden tiles. Lucky Spin is unlocked by a 3-star win (pendingSpinLevel).
- Web preview is a static export — rerun test_react_native_expo_project to rebuild it after code changes.
